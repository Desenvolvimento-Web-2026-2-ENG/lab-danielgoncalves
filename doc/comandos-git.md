# Guia de Comandos Git

Registro rápido dos principais comandos utilizados para versionar e publicar o projeto no GitHub Pages.

## Fluxo Básico de Versionamento

```bash
# Verificar arquivos modificados ou não rastreados
git status

# Adicionar todas as alterações para a área de staging
git add .

# Salvar um ponto na história do repositório
git commit -m "Reestrutura projeto e organiza navegacao do portfolio"

# Enviar os commits locais para o repositório remoto
git push origin main
