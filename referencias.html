    • 3. Links (Relativos vs. Absolutos) e Imagens

    A tag cria hiperlinks através do atributo href. Saber diferenciar caminhos relativos e absolutos evita links quebrados ao publicar o site.

    Regras de navegação

    • Caminho relativo: Parte da localização do arquivo atual. Ex.: lab/01/index.html (entra em pastas) ou ../../index.html (sobe dois níveis na árvore de diretórios).
    • Link de fragmento (âncora): Usa #id-do-elemento para saltar para uma seção da mesma página.
    • Caminho absoluto: Inclui o protocolo completo (https://...). Ao apontar para sites externos, recomenda-se usar target="_blank" junto com rel="noopener noreferrer".
    • Imagens (): Exige os atributos src (caminho da imagem) e alt (texto alternativo descritivo para acessibilidade).

    4. Git e GitHub Pages

    O GitHub Pages publica diretamente os arquivos estáticos do repositório. Arquivos Markdown (.md) são processados automaticamente pelo Jekyll e convertidos em páginas .html na URL pública.

    Boas práticas para deploy

    • Mantenha sempre um arquivo index.html na raiz do repositório para servir como página inicial.
    • Evite espaços e letras maiúsculas em nomes de pastas e arquivos, pois servidores Linux diferenciam maiúsculas de minúsculas (case-sensitive).
    • Sempre verifique o status e envie todas as alterações com git add, git commit e git push.
